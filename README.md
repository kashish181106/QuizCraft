
# QuizCraft: Flashcard & Quiz Trainer

## About the Project
QuizCraft is a beginner-friendly Python quiz application that allows users to answer questions, check their scores, and improve their knowledge.

## Features
- Loads questions from a text file.
- Displays questions in random order.
- Allows users to choose the number of questions.
- Checks answers regardless of uppercase or lowercase letters.
- Displays the final score and percentage.
- Shows incorrect answers with their correct answers.
- Provides a Play Again option.

## Technologies Used
- Python
- File Handling
- Lists and Dictionaries
- Functions
- Loops and Conditional Statements

## How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Make sure Python is installed.
4. Run the following command:

```bash
python main.py
```
